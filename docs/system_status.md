# 功能实现状态说明

## 已实现功能

| 功能 | 实现状态 | 说明 |
|---|---|---|
| React SPA 前端 | 已实现 | 提供画像、路径、学习、评估、资源与任务中心 |
| FastAPI 后端 | 已实现 | 提供完整学习流程 API、SSE 任务流和 RAG Tutor |
| 任务状态机多智能体工作流 | 已实现 | BackgroundTask + Transactional Outbox，包含画像、规划、内容、审核、讲义、评估、资源与推荐角色 |
| 学生画像提取 | 已实现 | 3-7 轮对话抽取八维画像，并通过诊断和评估证据持续更新 |
| PostgreSQL 全文知识库 | 已实现 | MinIO 存储，支持解析、分块、版本化索引、检索与引用 |
| 个性化讲义生成 | 已实现 | 基于画像和 RAG 内容生成 |
| 题库生成 | 已实现 | 支持选择题和简答题 |
| 思维导图生成 | 已实现 | 输出结构化树并通过 React Flow 渲染，支持讲义章节联动 |
| 学习计划生成 | 已实现 | 根据画像生成阶段计划 |
| PPTX 生成 | 已实现 | 生成并下载 PowerPoint 文件 |
| RAG 来源引用 | 已实现 | 返回 source、page、chunk_id |
| RAG 智能答疑 | 已实现 | 改造 tutor_node |
| Agent 执行轨迹 | 已实现 | 持久化角色、轮次、状态、摘要和产物，前端任务中心可视化 |
| 内容审核返修闭环 | 已实现 | Reviewer 不通过时触发一次定向返修与复审 |
| 环境变量示例 | 已实现 | 新增 .env.example |
| 依赖版本锁定 | 已实现 | 修改 requirements.txt |
