# EduAgentX — 作品说明书

## 1. 项目背景

EduAgentX 是一个面向大学课程的多智能体个性化辅导系统，基于大语言模型、RAG（检索增强生成）和 LangGraph 多智能体协作技术，为学生构建八维学习画像、搜索课程知识库、生成个性化学习材料、规划学习路径并回答问题。

本项目为 2026 年"中国软件杯"大学生软件设计大赛参赛作品。

### 1.1 赛题需求对应

| 赛题要求 | EduAgentX 实现 |
|---|---|
| 多智能体协作 | LangGraph 编排：画像对话 Agent、路径规划 Agent、内容生成 Agent、评估 Agent、推荐 Agent |
| 个性化学习 | 八维学习者画像（知识深度、前置掌握、概念理解、问题解决、实践能力、学习节奏、资源偏好、错误模式） |
| 知识库检索 | RAG 管线：上传 → 解析 → Chunk → FTS/Index → 搜索 → Tutor 引用 |
| 多模态资源 | 文档、思维导图、题库、PPTX 课件、代码 ZIP、交互式学习卡片、案例推演、概念模拟 |
| 学习路径规划 | DAG 路径图、节点解锁、画像自适应、路径修订 |
| 评估与掌握度 | 自适应评估生成、自动评分、Mastery 更新、画像反馈 |
| 动态推荐 | 基于画像 + 进度 + 评估证据的可解释推荐引擎 |

## 3. 多智能体设计

### 3.1 智能体编排

系统采用 LangGraph 进行多智能体编排，各智能体分工协作：

1. **画像对话 Agent**：通过 3-7 轮对话，从学生回答中抽取八维学习特征，构建个性化画像
2. **诊断 Agent**：根据画像调整诊断题目难度，评估学生当前水平
3. **路径规划 Agent**：结合画像和诊断结果，生成个性化 DAG 学习路径
4. **内容生成 Agent**：为每个学习节点生成讲义、思维导图、题库
5. **评估 Agent**：基于画像中的错误模式生成针对性评估题目，自动评分
6. **推荐 Agent**：基于画像 + 进度 + 评估证据生成可解释推荐

### 3.2 智能体通信

- 通过 PostgreSQL 共享状态（Outbox 模式）
- 异步任务队列（BackgroundTask + TaskEvent）
- SSE 实时推送任务状态
- 幂等任务设计（idempotency_key）

## 4. 八维学习画像

### 4.1 八个核心维度

| 维度 | 说明 | 数据类型 |
|---|---|---|
| knowledge_depth | 当前知识基础深度 | float (0-1) |
| prerequisite_mastery | 前置知识掌握度 | float (0-1) |
| concept_grasp | 概念理解能力 | float (0-1) |
| problem_solving | 问题解决能力 | float (0-1) |
| practice_ability | 实践迁移能力 | float (0-1) |
| learning_pace | 学习节奏 | enum (fast/moderate/slow) |
| resource_preference | 资源偏好 | list[str] |
| error_pattern | 常见错误模式 | dict[str, float] |

### 4.2 画像数据来源

- **对话式画像**：3-7 轮对话抽取（conversation_profile）
- **诊断结果**：诊断测试成绩（diagnostic_result）
- **评估成绩**：正式评估表现（assessment_attempt）
- **手动修正**：用户自主调整（manual_correction）

### 4.3 画像应用场景

- **诊断**：基础弱 → 起始题更基础；节奏慢 → 更多分步题
- **路径规划**：基础弱 → 补基础节点；偏项目 → 加项目实践节点
- **内容生成**：概念弱 → 更多类比；偏代码 → 增加 code example
- **评估生成**：error_pattern 命中 → 针对性变式题
- **推荐**：error_pattern → 针对性复习；concept_grasp 低 → 推荐提问 Tutor

## 5. 个性化学习路径

### 5.1 路径模型

- DAG（有向无环图）结构
- 节点解锁机制（前置节点完成 → 后续节点解锁）
- 版本管理（路径修订生成新版本）
- 画像自适应（基础弱 → 补基础；时间少 → 节点更短）

### 5.2 路径修订

- 连续评估失败触发路径修订推荐
- 用户确认后创建 RevisionRequest
- 异步执行路径修订，生成新版本

## 6. 多模态资源生成

### 6.1 资源类型

| 类型 | 说明 | 生成方式 |
|---|---|---|
| 讲义 (Unit Content) | 结构化课程内容 | LLM 生成 + 画像个性化 |
| 思维导图 | 知识结构图 | 从讲义内容提取 |
| 题库 | 练习题目 | LLM 生成 + 画像个性化 |
| PPTX 课件 | PowerPoint 演示文稿 | 确定性生成（无 LLM） |
| 代码 ZIP | 可下载代码项目 | 确定性生成 + 安全检查 |
| 交互式学习卡片 | 翻卡练习 | 确定性生成 |
| 案例推演 | 逐步案例分析 | 确定性生成 |
| 概念模拟 | 状态变化模拟 | 确定性生成 |

### 6.2 安全限制（代码 ZIP）

- 禁止恶意命令（rm -rf, fork bomb 等）
- 禁止外部下载脚本（wget, curl）
- 禁止危险函数（eval, exec, system）
- 禁止危险文件扩展名（.sh, .bat, .exe）
- 单文件最大 100KB，ZIP 最大 500KB

## 7. 评估 / Mastery / Adaptation

### 7.1 评估流程

1. 基于画像生成评估题目（error_pattern → 针对性变式题）
2. 学生提交答案
3. 自动评分（单选、多选、判断、简答）
4. 写入 StudentProfileEvidence
5. 更新 Mastery 和画像维度
6. 触发推荐引擎

### 7.2 Mastery 模型

- 节点级 Mastery（0-100）
- 基于评估成绩和完成状态计算
- 低于 60% 触发复习推荐

## 8. 知识库与 Tutor

### 8.1 RAG 管线

```
上传资料 → 存储原文件 → 解析文本 → Chunk → FTS/Index → 搜索 → Tutor 引用
```

### 8.2 Tutor 回答规范

- 优先使用知识库 chunk
- 给出引用（文件名、页码、段落标题）
- 无知识命中时明确说明
- 不编造文档内容

## 11. 创新点

1. **八维学习者画像**：超越传统标签，通过对话式抽取 + 多源证据融合构建深度画像
2. **画像驱动的全链路个性化**：画像不是展示数据，而是真正影响诊断、路径、内容、评估、推荐的核心输入
3. **多智能体协作**：LangGraph 编排，各智能体分工明确，通过 Outbox 模式保证一致性
4. **可解释推荐引擎**：每条推荐都附带证据和原因，用户可接受/忽略/稍后
5. **多模态资源生成**：8 种资源类型，确定性生成 + LLM 生成结合，安全限制完备
6. **路径自适应**：基于评估证据自动触发路径修订建议，用户确认后执行
